# سجلّ الطيران — مهند

Learning tracker for the Photography Unit, Moomken Media Center (8 Nov – 31 Dec 2026).

- Static site (GitHub Pages): `index.html`, `base.css`, `app.css`, `engine.js`, `content.js`, `theme.js`
- Edit the path (tasks, links, habits, resources) in `content.js`
- Progress is saved in a private GitHub Gist, file `muhannad-progress.json` — each device needs the Gist ID and a token with the `gist` scope (entered in «إعدادات الحفظ»)
- Manager PIN: set in `content.js` (`pin`)
- Studies count for 25% of overall progress; an exam week is saved if the weekly study goal is met
